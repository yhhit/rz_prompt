# 软件界面多风格 UI 提示词资产库（`rz_prompt`）

本仓库用于集中管理与维护多行业、多终端形态的软件界面（UI）设计参数库与完整套图生成提示词模板，旨在生成审美现代、视觉特征鲜明且高辨识度的软件界面素材。

详细的模板维护、格式校验与业务库同步导入流程请查阅 **[deploy/DEPLOYMENT.md](deploy/DEPLOYMENT.md)**。

## 核心设计约束

1. **多终端视口与组件尺度差异化**
   - 覆盖手机端（`390×844`）、HMI 触控屏（`1024×768`）、平板端（`1366×1024`）、主流桌面端（`1366×768` / `1440×900` / `1512×982`）、专业工作站（`1920×1080`）及超宽屏（`2560×1440`）。
   - 相邻套系必须在目标分辨率、整体缩放、背景表面材质、导航骨架、控件密度、字体层级、边框圆角与阴影深度中至少拉开 **5 个以上维度**的差异，杜绝“同骨架仅换主色”。
2. **色彩与时代审美规范**
   - **移除深蓝色背景同质化倾向**：明确排除千篇一律的深蓝色大屏/科技蓝底色主题，平衡浅灰、纸白、暖米色、碳黑终端、毛玻璃与高对比工业灰等多元表面语言。
   - **现代原生桌面与专业工具质感**：遵循现代 Windows / macOS 桌面应用或垂直行业专业软件规范，禁止出现 2010 年以前的老旧操作系统拟物风，停止生成传统通用 SaaS 管理后台表格风。
3. **工控软件端型严格区分（`Industrial Terminal Type`）**
   - 工业控制系统细分为四类互斥终端形态，严禁把触控面板与工程上位机混排：
     - `触摸屏面板端 / HMI Panel`
     - `工程上位机 / Engineering Workstation`
     - `SCADA站控监视端 / Station Monitoring Console`
     - `维护调试上位机 / Maintenance Workstation`
