# 建模软件 UI参数（50套）

## 生成目标

生成 50 套建模软件 UI 参数。该类别必须优先理解为以下软件范畴，而不是普通后台、数据大屏、办公文档或设计素材平台：

- CAD / 二维制图软件
- 三维建模软件
- 参数化建模工具
- 工程建模工作台
- 装配结构型
- 仿真前处理建模界面
- 资源浏览 / 对象管理界面

核心要求：

1. 必须具有专业桌面软件气质。
2. 必须有画布/视图中心、工具栏、对象树、属性区等建模工作区特征。
3. 不包含具体建模业务逻辑，但要有明确的建模软件骨架。
4. 差异化主要来自：建模子类型、画布类型、面板停靠方式、工具密度、属性面板组织方式。

- 偏专业工具感，强调对齐、分栏、边框、工具密度。
- 可使用浅灰、深灰、深色专业、线框极简、少量 macOS 精细半透明风格。
- 不使用普通 SaaS 后台骨架。

- 不使用数据大屏驾驶舱骨架。
- 不使用纯办公文档/列表页骨架。

## 二、建模软件真正的差异来源

建模软件不应主要靠以下方式拉差异：

- 单纯换配色
- 卡片化后台布局
- 互联网产品化大留白
- 大面积营销质感
- 奇怪装饰图标

真正可用的差异化维度：

1. 子类型
2. Canvas Type
3. Panel Docking Style
4. Tool Density
5. Inspector Structure
6. Viewport / Object Tree / Property Grid 占比
7. Windows / macOS / Linux 工程应用气质

## 四、建模软件结构骨架禁忌

### 常见错误骨架

以下结构会让建模软件跑偏：

- SaaS 后台左侧菜单 + 表格中心骨架
- 数据分析 dashboard / 大屏驾驶舱骨架
- 工控触摸屏大按钮骨架
- 移动 App 首页 / 卡片列表骨架
- 办公内容列表骨架
- 只有卡片和表单，缺少画布、工具栏、对象树、属性面板

### 正确骨架

- `CAD/二维制图`: 顶部工具栏 + 左对象树 + 中央画布 + 底部命令区
- `三维建模`: 中央视口 + 左工具条 + 右属性检查器 + 底部状态栏
- `参数化建模`: 参数表 + 约束面板 + 视图窗口 + 日志区
- `工程建模工作台`: 对象树 + 模型视图 + 属性网格 + 命令/日志区
- `装配/结构工作台`: 装配树 + 结构视图 + 对象属性 + 状态栏
- `仿真前处理`: 网格/模型视图 + 参数区 + 求解设置 + 日志
- `模型资源管理`: 资源列表 + 预览视图 + 属性抽屉 + 标签过滤

## 低/中低分辨率差异化规则

本类 UI 参数必须覆盖不同低分和中低分桌面/终端画布，不能全部使用高分工作站或大屏分辨率。

- 每套真实参数必须包含 `Target Viewport / UI Scale`。
- 优先使用低/中低分辨率：`800×600`、`960×540`、`960×600`、`1024×576`、`1024×600`、`1024×768`、`1152×720`、`1152×864`、`1200×800`、`1280×720`、`1280×800`。
- 禁止默认 `1200×800`、`1280×720`、`1280×800`、`1280×720`、`1280×800`、`1280×800`、`1280×720`。
- 每 10 套至少出现 6 种不同分辨率；相邻参数宽或高至少一项明显不同。
- 分辨率降低时同步放大字号、行高和控件高度，避免密集小字与整屏细表格。


## 少量套数强差异化规则

当某个大类下只有 6–10 套真实参数时，不能只做同一骨架的配色变化；每套都必须像不同软件。生成时优先遵守以下硬约束：

- 每套必须有不同的 `Target Viewport / UI Scale`，并优先使用本文件“低/中低分辨率差异化规则”中的分辨率池；不得默认高分工作站、大屏或超宽画布。
- 每套必须有明确的 `First-glance Signature`：用户第一眼能看到的差异，例如低分手机卡片、低分桌面三栏、紧凑图表网格、小窗口工具面板、低分画布工作区、短表格阅读页、浮动小窗。
- 每套必须拉开 `Component Scale`：有的整体控件很小很密，有的按钮和列表很大，有的中等办公密度，有的触控大字号。
- 每套必须拉开背景与容器语言：纯白/浅灰/米色/暖灰/浅绿灰/浅玻璃/硬边框/网格底/纸张底，不允许连续多套都是白底卡片。
- 每套至少在 `目标分辨率、整体缩放、背景颜色、容器形态、导航骨架、控件密度、字体尺度、边框/阴影` 中变化 5 项以上。
- 如果两套同属浅色风，必须一个偏冷灰硬边框，一个偏暖色大留白，或者一个高密度表格，一个大控件卡片，不能只换主色。
