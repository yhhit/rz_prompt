# 工业控制系统 UI参数（100套）

## 生成目标

生成 100 套工业控制系统 UI 参数。该类别必须优先理解为 `PLC / HMI / SCADA / 工程桌面应用 / 双栏操作维护型软件`，而不是普通 Web 后台、工业云平台或数据大屏。

工控类差异化不应主要依靠奇怪颜色、夸张圆角、玻璃拟态、花哨动效，而应主要依靠：

- 子类型
- 页面骨架
- 操作场景
- 平台 / 年代
- 信息密度
- 状态区 / 参数区 / 控制区 / 警示区 / 趋势区的组织方式

---

## 一、总风格规则

- 背景色应限制在浅工业灰、冷灰、米灰、银灰、深蓝灰、石墨灰、深炭灰等安全范围内。
- 状态色以绿色、橙色、黄色、红色、青色为主，用于运行、告警、警示、选中、通信。
- 禁止奇怪背景色、糖果色、霓虹色、大面积紫粉色。
- 禁止游戏 HUD、赛博朋克、科幻雷达屏、营销网页式视觉。
- 禁止普通 SaaS 左侧菜单后台骨架，除非子类型明确为工程桌面配置工具且导航是对象树/工程树。
- 禁止云平台首页、云服务入口、用户中心、互联网平台式顶部图标导航。

## 工控端类型区分规则

工控类必须显式区分运行载体，不能把触摸屏面板端和上位机混在一起。每套工业控制系统 UI 参数都应包含 `Industrial Terminal Type` 字段，优先级高于颜色、圆角和阴影。

- `触摸屏面板端 / HMI Panel`：设备本机屏、嵌入式工控触摸屏、WinCC Runtime 运行画面；典型特征是 800×480、1024×600、1024×768、1280×720 横屏，大按钮、大字号、状态灯、硬边框、单屏/分页操作，通常没有工程树、复杂菜单和密集表格。
- `工程上位机 / Engineering Workstation`：Windows/Linux 桌面工程配置、PLC 参数配置、点表映射、组态编辑、维护调试；典型特征是 1366×768、1440×900、1600×900、1920×1080，鼠标键盘操作，小控件、高密度表格、对象树、属性栏、工具栏、底部日志。
- `SCADA站控监视端 / Station Monitoring Console`：控制室监控终端、站控大屏/工作站、趋势警示监视；典型特征是 1920×1080 或更宽，趋势图、警示条、状态摘要、监控总览、事件列表，控件中等偏大但不是 HMI 大按钮。
- `维护调试上位机 / Maintenance Workstation`：工程维护软件、联机调试、双栏操作日志；典型特征是左右/三栏面板、操作按钮、参数输入、日志控制台、状态标签，介于配置上位机和运行监控端之间。

判断优先级：如果出现 HMI、Touch、800×480、1024×600、1024×768、大按钮、现场操作屏，标为触摸屏面板端；如果出现 Engineering、PLC 参数、点表、组态、对象树、属性栏、高密度表格，标为工程上位机；如果出现 Station、SCADA、趋势、警示、监控总览，标为 SCADA站控监视端；如果出现维护、调试、双栏操作日志，标为维护调试上位机。

## 三、结构骨架禁忌

### 工控类常见错误骨架

以下结构会让图像变成“工业云后台 / 工业 SaaS 平台”，应避免：

- 左侧 SaaS 应用菜单
- 顶部互联网图标导航
- 顶部 + 左侧双重平台导航
- 云平台首页 / 云服务入口 / 用户中心
- 卡片式平台总览首页
- 底部移动 App Tab 导航
- 大面积玻璃拟态悬浮卡片

### 工控类正确骨架

- `参数配置型`: 左工程树 + 中心参数表 + 右属性栏 + 底部消息
- `组件架组态型`: 中央组件架/组件图 + 下方组件表 + 右属性栏
- `点表映射型`: 高密度点表表 + 映射编辑区 + 批量操作条
- `现场操作屏型`: 顶部状态条 + 中央大按钮 + 底部警示/状态条
- `参数设定型`: 页签参数块 + 大尺寸输入区 + 固定确认区
- `监控总览型`: 节点总览 + 趋势图 + 警示列表 + 状态摘要
- `双栏操作维护型`: 左树控件 + 中操作区 + 右日志/属性区

## 少量套数强差异化规则

当某个大类下只有 6–10 套真实参数时，不能只做同一骨架的配色变化；每套都必须像不同软件。生成时优先遵守以下硬约束：

- 每套必须有不同的 `Target Viewport / UI Scale`：例如手机 390×844、平板 1366×1024、桌面 1440×900、工作站 1920×1080、HMI 1024×768、双屏/超宽 2560×1440。
- 每套必须有明确的 `First-glance Signature`：用户第一眼能看到的差异，例如大标题手机卡片、硬边框工控按钮、深色终端、Ribbon 工具栏、三维视口、图表矩阵、浮动小窗。
- 每套必须拉开 `Component Scale`：有的整体控件很小很密，有的按钮和列表很大，有的中等办公密度，有的触控大字号。
- 每套必须拉开背景与容器语言：纯白/浅灰/米色/深蓝/黑灰/玻璃/硬边框/网格底/终端底，不允许连续多套都是白底卡片。
- 每套至少在 `目标分辨率、整体缩放、背景颜色、容器形态、导航骨架、控件密度、字体尺度、边框/阴影` 中变化 5 项以上。
- 如果两套同属浅色风，必须一个偏冷灰硬边框，一个偏暖色大留白，或者一个高密度表格，一个大控件卡片，不能只换主色。
