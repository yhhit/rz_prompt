# 工业控制系统 UI参数（100套）

## 生成目标

生成 100 套工业控制系统 UI 参数。该类别必须优先理解为 `PLC / HMI / SCADA / 工程桌面应用 / 双栏操作维护型软件`，而不是普通 Web 后台、工业云平台或数据大屏。

工控类差异化不应主要依靠奇怪颜色、夸张圆角、玻璃拟态、花哨动效，但必须允许在“合理工业色彩”、“低/中低分辨率终端”和“独特工控面板形态”上拉开明显差距。差异化应同时来自：

- 子类型
- 页面骨架
- 操作场景
- 平台 / 年代
- 目标终端分辨率与缩放比例，优先覆盖低分辨率和中低分辨率 HMI
- 工业安全配色族
- 低文字量 / 低表格量 / 图形化状态表达
- 状态区 / 控制区 / 警示区 / 设备示意区 / 趋势区 / 仪表区的组织方式

---

## 一、总风格规则

- 背景色应限制在浅工业灰、冷灰、米灰、银灰、中灰、石墨灰、深炭灰等安全范围内。
- 状态色以绿色、橙色、黄色、红色、青色为主，用于运行、告警、警示、选中、通信。
- 禁止奇怪背景色、糖果色、霓虹色、大面积紫粉色。
- 禁止游戏 HUD、赛博朋克、科幻雷达屏、营销网页式视觉。
- 禁止普通 SaaS 左侧菜单后台骨架，除非子类型明确为工程桌面配置工具且导航是对象树/工程树。
- 禁止云平台首页、云服务入口、用户中心、互联网平台式顶部图标导航。

## 工控端类型区分规则

工控类必须显式区分运行载体，不能把触摸屏面板端和上位机混在一起。每套工业控制系统 UI 参数都应包含 `Industrial Terminal Type` 字段，优先级高于颜色、圆角和阴影。

- `触摸屏面板端 / HMI Panel`：设备本机屏、嵌入式工控触摸屏、WinCC Runtime 运行画面；典型特征是 800×480、1024×600、1024×768、1280×720 横屏，大按钮、大字号、状态灯、硬边框、单屏/分页操作，通常没有工程树、复杂菜单和密集表格。
- `工程上位机 / Engineering Workstation`：Windows/Linux 桌面工程配置、PLC 参数配置、点表映射、组态编辑、维护调试；典型特征不应默认现代高分桌面，而应主要是低分辨率工控机、旧式上位机和维修笔记本，如 640×480、720×480、800×600、960×540、960×600、1024×576、1024×600、1024×768。鼠标键盘操作，但字号、控件和行高必须明显放大，表格行数和属性字段大幅减少，优先使用大号状态块、设备槽位、短表格、少量参数卡。
- `SCADA站控监视端 / Station Monitoring Console`：控制室监控终端、站控大屏/工作站、趋势警示监视；典型特征是 1920×1080 或更宽，趋势图、警示条、状态摘要、监控总览、事件列表，控件中等偏大但不是 HMI 大按钮。
- `维护调试上位机 / Maintenance Workstation`：工程维护软件、联机调试、双栏操作日志；典型特征是左右/三栏面板、操作按钮、参数输入、日志控制台、状态标签，介于配置上位机和运行监控端之间。

判断优先级：如果出现 HMI、Touch、800×480、1024×600、1024×768、大按钮、现场操作屏，标为触摸屏面板端；如果出现 Engineering、PLC 参数、点表、组态、对象树、属性栏、鼠标键盘操作，标为工程上位机，但上位机也必须优先随机使用低分辨率和中低分辨率，不得默认高分桌面；如果出现 Station、SCADA、趋势、警示、监控总览，标为 SCADA站控监视端；如果出现维护、调试、双栏操作日志，标为维护调试上位机。

## 三、结构骨架禁忌

### 工控类常见错误骨架

以下结构会让图像变成“工业云后台 / 工业 SaaS 平台”，应避免：

- 左侧 SaaS 应用菜单
- 顶部互联网图标导航
- 顶部 + 左侧双重平台导航
- 云平台首页 / 云服务入口 / 用户中心
- 卡片式平台总览首页
- 底部移动 App Tab 导航
- 大面积玻璃拟态悬浮卡片

### 工控类正确骨架

- `参数配置型`: 低分工程面板优先，左侧少量设备槽位 + 中央 4–8 个大号参数块 + 右侧短属性区 + 底部短消息条
- `组件架组态型`: 中央组件架/组件图 + 下方组件表 + 右属性栏
- `点表映射型`: I/O 通道块矩阵 + 4–8 行短映射表 + 批量操作条，禁止整屏高密点表
- `现场操作屏型`: 顶部状态条 + 中央大按钮 + 底部警示/状态条
- `参数设定型`: 页签参数块 + 大尺寸输入区 + 固定确认区
- `监控总览型`: 节点总览 + 趋势图 + 警示列表 + 状态摘要
- `双栏操作维护型`: 左状态卡 + 中央大操作按钮/拨杆 + 右短日志或事件跑马条

## 五、工控安全配色与分辨率范围

### 配色使用原则

工控类不能使用冷暗色、深灰、黑灰这类大面积暗色背景。每套参数必须选择一个明确的中浅工业配色族，并在背景、面板、主操作色、警示色、边框色上形成可见差异。色彩应服务于设备状态和工业可读性，不做娱乐化、霓虹化、糖果化。

强制差异规则：

- 连续 3 套参数不得使用同一种背景族，例如不能连续 3 套都是白底/浅灰。
- 禁止大面积深色背景：不要冷暗色、深灰、黑灰、石墨黑、深炭灰、深墨绿灰或任何接近黑底大屏的视觉。
- 深色只允许作为小面积文字、边框、状态图标、按钮描边或警示标签使用，不得作为页面 `bg` 或大面积 `surface`。
- 相邻参数的 `Target Viewport / UI Scale` 不得只差几十像素；必须跨终端类型或跨缩放等级。
- 同属浅色时，要在冷暖、边框强度、面板密度上拉开：例如冷灰硬边框、暖米触控面板、浅青灰监视端、砂岩米色旧式HMI。
- 状态色可以出现绿、黄、橙、红、青绿，但必须是工业状态/通信/选中/报警用途，不做大面积装饰渐变。

### 工控目标分辨率梯度

生成 100 套时只允许低分辨率和中低分辨率 HMI/面板端、低分上位机、低分站控端。彻底禁止高分辨率、超宽、4K 画布，不允许出现 `1680×1050`、`1920×1080`、`1920×1200`、`2560×1080`、`2560×1440`、`3840×1080`、`3840×2160` 等高分/超宽/4K 分辨率。

| 终端类型 | 推荐分辨率 / 画布 | 缩放与控件尺度 |
|---|---|---|
| 极小型 HMI 面板 | `320×240`, `400×240`, `480×272` | 160–200%；按钮 56–84h；极少文字；最多 4–8 个主控件 |
| 小型 HMI 面板 | `480×320`, `640×360`, `640×480`, `720×480` | 140–180%；按钮 56–88h；大状态灯和大读数 |
| 宽屏小型 HMI | `800×480`, `854×480`, `960×540` | 125–160%；按钮 48–76h；图形化分区 |
| 中型 HMI 面板 | `800×600`, `1024×600`, `1024×768`, `1152×720` | 115–145%；按钮 44–72h；少表格，多状态块 |
| 工业平板 / 低分桌面 | `1024×576`, `1152×864`, `1280×720`, `1280×800`, `1280×1024` | 100–130%；中等控件；允许少量参数表 |
| 工程上位机低分主池 | `640×480`, `720×480`, `800×480`, `800×600`, `960×540`, `960×600`, `1024×576`, `1024×600`, `1024×768` | 130–170%；字号 16–24；控件 44–64h；表格最多 3–6 行 |
| 工程上位机少量补充 | `1152×720`, `1152×864`, `1200×800`, `1280×720`, `1280×768`, `1280×800`, `1280×960`, `1280×1024` | 115–135%；只作为少量补充；字号不低于 15；不得使用密集小字和整屏表格 |
| 低分站控监视端 | `1024×576`, `1024×600`, `1024×768`, `1152×720`, `1152×864`, `1280×720`, `1280×768`, `1280×800`, `1280×1024` | 115–145%；趋势小窗和状态图为主，禁止高分大屏 |
| 竖屏/柜门面板 | `240×400`, `272×480`, `320×480`, `480×800`, `600×1024` | 145–200%；纵向状态灯、大按钮、少文字 |

分辨率差异要求：

- 100 套中至少覆盖 32 种不同分辨率或画布形态，其中低于 `1280×800` 的分辨率不得少于 60 套。
- 工程上位机不得默认高分辨率：工程上位机相关参数中，至少 85% 必须使用 `640×480`、`720×480`、`800×480`、`800×600`、`960×540`、`960×600`、`1024×576`、`1024×600`、`1024×768` 这些低分辨率主池。
- 工程上位机每套分辨率必须随机拉开：相邻工程上位机参数不能同为 1280 宽或同为 1024 高；若宽高接近，必须改变横竖比例、缩放比例和布局骨架。
- `1152×720`、`1152×864`、`1200×800`、`1280×720`、`1280×768`、`1280×800`、`1280×960`、`1280×1024` 只能作为少量上位机补充分辨率，合计不得超过工程上位机参数的 15%。
- 全部工控参数禁止使用 `1366×768`、`1440×900`、`1600×900`、`1680×1050`、`1920×1080`、`1920×1200`、`2560×1080`、`2560×1440`、`3840×1080`、`3840×2160` 等高分、超宽、4K 分辨率。
- 任何站控监视端也必须使用低分或中低分画布，优先 `1024×576`、`1024×600`、`1024×768`、`1152×720`、`1152×864`、`1280×720`、`1280×800`，不得使用大屏/超宽/4K。
- 每 10 套内至少出现 7 种不同分辨率，并且至少 5 套必须低于 `1280×800`。
- 相邻两套参数的画布宽度或高度至少有一项差异 ≥160px；若同宽或同高，必须改变横竖屏、缩放比例或终端类型。
- 不允许出现 `1366×768`、`1440×900`、`1600×900`、`1680×1050`、`1920×1080`、`1920×1200`、`2560×1440`、`3840×2160` 等高分辨率。
- `Target Viewport / UI Scale` 必须写清楚像素、缩放比例、控件高度或行高，不能只写 desktop / station / HMI。

## 低文字量与独创性规则

工控类不能只生成密密麻麻的文字、表格、属性栏。尤其是 HMI/触摸屏面板端，应优先通过图形化设备状态、按钮、灯号、仪表、流程示意和分区形状表达，而不是铺满文本。

强制规则：

- 100 套中至少 55 套应为 `低文字量 / 低表格量`：单屏主要文字标签控制在 12–28 个以内，表格行数不超过 6 行，或完全无表格。
- HMI/触摸屏端禁止高密度表格作为主体；只允许大按钮、状态灯、数值读数、设备示意、流程管线、简短警示条。
- 工程上位机可以有表格，但不得连续多套以“左树 + 中表 + 右属性”为主；每 10 套最多 3 套表格主体。
- 工程上位机字体和控件必须比普通开发工具大很多：正文/表格字号建议 `16–20`，标题 `22–32`，表格行高 `42–58h`，控件高度 `44–64h`；禁止 `11/12/13px` 小字、`20–32h` 密集行高、整屏 10 行以上点表。
- 工程上位机表格必须很短：普通参数表 3–6 行为主，最多 8 行；点表映射优先用通道块、状态灯矩阵、短表格，不要铺满密集点表。
- 每套必须有一个独创性的 `First-glance Signature`，且不能只写参数表、点表、属性栏。优先使用：环形仪表盘、设备剖面示意、管线流程图、九宫格大按钮、棋盘式状态灯、纵向柜门面板、横向警示跑马条、实体控制柜面板、分段流程卡、旋钮/拨杆/急停按钮、趋势小窗、设备槽位图、模块化状态岛。
- `Panel Composition` 中必须至少出现 1 个非表格主体：设备示意、状态灯矩阵、流程管线、按钮矩阵、仪表盘、告警条、读数卡、控制柜面板、趋势窗、槽位图。
- 避免整屏都是表格、日志、长文本、参数字段；避免所有控件都小而密。



当某个大类下只有 6–10 套真实参数时，不能只做同一骨架的配色变化；每套都必须像不同软件。生成时优先遵守以下硬约束：

- 每套必须有不同的 `Target Viewport / UI Scale`，并且差异要足够大、优先低分辨率：例如 `320×240 极小HMI @200%`、`400×240 条形HMI @190%`、`480×272 小宽屏HMI @175%`、`640×480 传统HMI @160%`、`640×480 低分上位机 @160%`、`720×480 维修上位机 @155%`、`800×600 低分上位机 @150%`、`960×540 低分上位机 @140%`、`1024×600 旧式上位机 @135%`、`1024×768 旧式上位机 @130%`。高于 `1280×800` 的上位机分辨率只能极少量出现。
- 每套必须有明确的 `First-glance Signature`：用户第一眼能看到的差异，例如极小屏四按钮面板、纵向柜门状态灯、九宫格大按钮、设备剖面示意、管线流程图、环形仪表盘、棋盘式状态灯、实体急停控制面板、模块槽位图、横向警示跑马条、双旋钮参数屏、低分辨率趋势小窗。
- 每套必须拉开 `Component Scale` 和文字密度：有的极少文字 4–8 个大控件，有的 12–20 个状态块，有的少量 4–6 行参数，有的中等工程密度；不能连续多套都是小字、高密表格、属性栏。
- 每套必须拉开背景与容器语言：冷灰白、浅工业灰、暖米灰、砂岩米色、浅青灰、淡灰绿、浅陶土灰、设备灰、水泥灰、控制柜米黄、灰绿旧式面板、中性金属灰、暖金属灰等中浅色工业底都可以使用；不要使用冷暗色、近黑冷色、深灰、黑灰或大面积深色背景，不允许连续多套都是白底卡片。
- 每套至少在 `目标分辨率、整体缩放、背景颜色、容器形态、导航骨架、控件密度、字体尺度、边框/阴影` 中变化 5 项以上。
- 如果两套同属浅色风，必须一个偏冷灰硬边框，一个偏暖色大留白，或者一个高密度表格，一个大控件卡片，不能只换主色。
