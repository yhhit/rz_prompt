# 设计软件 UI参数（50套）

## 生成目标

生成50套设计软件UI参数。界面应具有专业创作工具感，适合画布、面板、工具栏、属性区、资源区等通用结构，但不包含具体设计业务逻辑。

## 风格要求

- 可比其他类别更注重质感和层次，但必须克制。
- 可使用深色、玻璃浅色、玻璃深色、线框极简。
- 避免艺术装置风、夸张色块、游戏化工具界面。
- 保持可用性和专业软件气质。

## 推荐风格方向

1. 深色画布中心风
2. 深海多面板风
3. 克制玻璃深色风
4. 克制玻璃浅色风
5. 浅色画布工具风
6. 线框极简画布风
7. 深灰黄绿面板风
8. 高对比创作面板风
9. macOS 半透明侧栏风
10. Windows 深灰画布工作区风
11. 资源浏览预览风
12. 浮动工具条风
13. 双侧检查器风
14. 低饱和专业深色风

## 技术栈 / 渲染范式优先规则

- Rendering Paradigm: `Professional creative application`
- UI Framework: `AppKit / SwiftUI / Qt / Electron-like shell`
- Component Language: `canvas, layer panel, inspector, asset panel, toolbar, floating palette, properties panel`
- Native Control Level: `medium / high`
- CSS Styling Level: `medium`

## OS / Era 使用规则

- 推荐 OS Family: `macOS / Windows / Web`
- 推荐 OS Era: `macOS Big Sur/Monterey/Ventura/Sonoma 专业创作软件`、`Windows 10/11 专业创作工具`
- 少量可用: `现代Web创作工具`
- 避免: `Windows XP/Win7 老工具`、`Industrial HMI`、`监控终端`、`普通SaaS后台`、`移动App`
- OS Visual Traits: `画布中心、多面板、浮动工具条、图层/资源/属性检查器、细线图标、精致层次`
- No Title Bar: `不要操作系统标题栏、不要窗口控制按钮；OS / Era 只体现在画布中心、多面板、浮动工具条、图层/资源/属性检查器和细线图标上`

## 平台 / OS / 控件 / 避免项

- Platform Style: `现代专业创作桌面软件`，强调 `画布中心 + 多面板`
- OS / Era: 优先 `macOS Big Sur/Sonoma 专业创作软件` 或 `Windows 10/11 设计工具气质`，少量现代Web创作工具
- Control Style: `画布`、`工具栏`、`属性面板`、`资源区`、`图层/细线图标控件`
- Avoid: 不要生成 `普通后台系统`、`数据分析看板`、`HMI/PLC工控屏`、`移动APP`、`办公文档页`、`纯表单卡片界面`

## 差异化规则

每套至少变化以下4项：

- 画布背景
- 面板透明度
- 圆角
- 工具栏密度
- 主色点缀
- 图标线宽
- 阴影/玻璃策略
- 动效节奏


## 少量套数强差异化规则

当某个大类下只有 6–10 套真实参数时，不能只做同一骨架的配色变化；每套都必须像不同软件。生成时优先遵守以下硬约束：

- 每套必须有不同的 `Target Viewport / UI Scale`：例如手机 390×844、平板 1366×1024、桌面 1440×900、工作站 1920×1080、HMI 1024×768、双屏/超宽 2560×1440。
- 每套必须有明确的 `First-glance Signature`：用户第一眼能看到的差异，例如大标题手机卡片、硬边框工控按钮、深色终端、Ribbon 工具栏、三维视口、图表矩阵、浮动小窗。
- 每套必须拉开 `Component Scale`：有的整体控件很小很密，有的按钮和列表很大，有的中等办公密度，有的触控大字号。
- 每套必须拉开背景与容器语言：纯白/浅灰/米色/深蓝/黑灰/玻璃/硬边框/网格底/终端底，不允许连续多套都是白底卡片。
- 每套至少在 `目标分辨率、整体缩放、背景颜色、容器形态、导航骨架、控件密度、字体尺度、边框/阴影` 中变化 5 项以上。
- 如果两套同属浅色风，必须一个偏冷灰硬边框，一个偏暖色大留白，或者一个高密度表格，一个大控件卡片，不能只换主色。
