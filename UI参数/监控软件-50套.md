# 监控软件 UI参数（50套）

## 生成目标

生成 50 套监控软件 UI 参数。该类别必须优先理解为以下软件范畴，而不是普通后台、工业 HMI 操作屏或赛博大屏：

- 值守终端界面
- 状态监视界面
- 趋势警示界面
- 状态总览界面
- 警示处理界面
- 区域监控总览界面

核心要求：

1. 必须具备持续监看的稳定感。
2. 必须有清晰的状态层级、警示层级和趋势层级。
3. 不包含具体监控业务逻辑，但要有明确的监控终端结构。
4. 差异化主要来自：子类型、面板骨架、趋势区与警示区组织方式、值守终端气质。

---

## 一、总风格规则

- 可偏深色、深海蓝、石墨灰、深炭灰、浅工业灰、浅站控灰。
- 状态色必须清晰但克制，禁止刺眼霓虹。
- 发光、网格、雷达、扫描线效果必须极度克制。
- 不使用游戏 HUD、赛博朋克大屏、营销式科技驾驶舱。
- 不使用普通互联网后台导航骨架。
- 不默认做成 PLC/HMI 现场操作屏，除非子类明确为站控操作终端。

## 二、监控软件真正的差异来源

监控软件不应主要靠以下维度拉差异：

- 夸张配色
- 大量霓虹发光
- 奇怪材质
- 炫酷动画
- 装饰性未来感图标

真正可用的差异化维度：

1. 子类型
2. 趋势区 / 警示区 / 状态区占比
3. 值守终端 or 站控终端 or 轻监控总览
4. 时间过滤方式
5. 深浅体系
6. 面板分区方式
7. 状态层级与警示层级表现方式

- Rendering Paradigm: `Monitoring terminal / operations console`
- UI Framework: `SCADA terminal / Qt / WPF / controlled Web console`
- Component Language: `alarm list, status panel, trend chart, event timeline, tree view, monitoring grid, operator console`
- Native Control Level: `medium / high`
- CSS Styling Level: `low / very low`

## OS / Era 使用规则

- 推荐 OS Family: `Windows / Linux / Monitoring Terminal`
- 推荐 OS Era: `Linux/Windows 工控终端`、`Windows 10/11 值守终端`、`近代监控站控终端`
- 少量可用: `Windows 7 传统站控/值守软件`
- 避免: `iOS/Android 移动端`、`macOS 创作软件`、`纯赛博大屏`、`SaaS后台首页`
- OS Visual Traits: `持续监看、状态层级清晰、警示队列、趋势区、克制深色或浅工业灰、少发光`
- No Title Bar: `不要操作系统标题栏、不要窗口控制按钮；OS / Era 只体现在值守终端、状态监视、警示队列和趋势面板结构上`

## 四、监控软件结构骨架禁忌

### 常见错误骨架

以下结构会让监控软件跑偏：

- 左侧 SaaS 应用菜单 + 业务后台首页
- 顶部互联网图标导航
- 纯表格后台骨架
- PLC/HMI 大按钮单屏操作骨架
- 设计软件画布中心骨架
- 移动 App 首页骨架
- 赛博驾驶舱 / 霓虹未来大屏

### 适合的正确骨架

- `值守终端`: 顶部状态条 + 中心监控网格 + 右警示列
- `状态监视`: 总览区 + 状态表 + 趋势区 + 警示区
- `趋势警示`: 上趋势主区 + 下警示列表 + 侧状态摘要
- `状态总览`: 状态卡网格 + 对象明细 + 摘要信息
- `警示处理`: 警示队列 + 详情区 + 处理动作区
- `区域监控总览`: 区域概览 + 状态块 + 趋势/警示侧栏

## 少量套数强差异化规则

当某个大类下只有 6–10 套真实参数时，不能只做同一骨架的配色变化；每套都必须像不同软件。生成时优先遵守以下硬约束：

- 每套必须有不同的 `Target Viewport / UI Scale`：例如手机 390×844、平板 1366×1024、桌面 1440×900、工作站 1920×1080、HMI 1024×768、双屏/超宽 2560×1440。
- 每套必须有明确的 `First-glance Signature`：用户第一眼能看到的差异，例如大标题手机卡片、硬边框工控按钮、深色终端、Ribbon 工具栏、三维视口、图表矩阵、浮动小窗。
- 每套必须拉开 `Component Scale`：有的整体控件很小很密，有的按钮和列表很大，有的中等办公密度，有的触控大字号。
- 每套必须拉开背景与容器语言：纯白/浅灰/米色/深蓝/黑灰/玻璃/硬边框/网格底/终端底，不允许连续多套都是白底卡片。
- 每套至少在 `目标分辨率、整体缩放、背景颜色、容器形态、导航骨架、控件密度、字体尺度、边框/阴影` 中变化 5 项以上。
- 如果两套同属浅色风，必须一个偏冷灰硬边框，一个偏暖色大留白，或者一个高密度表格，一个大控件卡片，不能只换主色。
