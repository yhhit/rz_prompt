# 管理系统 UI参数（200套）

## 生成目标

生成200套管理系统UI参数。整体应偏企业级、清晰、稳定、可长时间使用，适合表格、表单、列表、卡片、配置页、详情页等通用管理界面。

## 风格要求

- 以浅色、柔和灰、暖白、中性色为主。
- 可少量使用深色专业后台风，但不应大面积使用大屏风格。
- 蓝色、紫色科技感方案总占比不超过15%。
- 避免业务字段、业务流程、行业术语，仅描述视觉参数。
- 视觉以现代为主；仅少量允许 Windows 7 时代传统内网系统气质，避免低质感 XP 老后台。

## 推荐风格方向

1. 明亮表格卡片风
2. 紧凑灰白表格风
3. 暖白分区表单风
4. 米白墨绿表单风
5. 奶白深棕卡片风
6. 青绿稳重侧栏风
7. 冷灰橙色分区风
8. 蓝灰低饱和后台风
9. 高对比线框表格风
10. 极简白底表格风
11. 深色专业后台风
12. 深蓝灰数据表格风
13. 浅玻璃侧栏风
14. 硬边框传统内网风
15. 高密度配置页风
16. 双栏详情抽屉风

## 技术栈 / 渲染范式优先规则

- Rendering Paradigm: `Web application`
- UI Framework: `React/Vue, Ant Design / Element Plus`
- Component Language: `form controls, data table, pagination, drawer, modal, tabs, two-level / three-level sidebar navigation, submenu tree`
- Native Control Level: `none`
- CSS Styling Level: `high`

## OS / Era 使用规则

- 推荐 OS Family: `Web / Windows`
- 推荐 OS Era: `现代 Web 企业后台 / Windows 10 / Windows 11`
- 少量可用: `Windows 7 传统内网系统`，仅用于少量老式企业管理端，不作为默认
- 避免: `Windows XP 老后台`、`iOS/Android 移动端`、`Industrial HMI`、`macOS 创作软件气质`
- OS Visual Traits: `现代SaaS表格与筛选器、二级/三级侧栏菜单、克制卡片、Windows 10/11 后台界面留白与圆角`
- No Title Bar: `不要操作系统标题栏、不要窗口控制按钮；OS / Era 只体现在Web后台控件、表格、筛选器、二级/三级侧栏菜单和卡片层次上`

## 平台 / OS / 控件 / 避免项

- Platform Style: `现代 Web 后台` 为主，少量可扩展到 `现代桌面管理界面`
- OS / Era: 优先 `现代Web / Windows 10/11 时代后台界面审美`，少量可用 `Windows 7 传统内网系统`，避免明显 `Windows XP` 老后台
- Control Style: `现代 SaaS 表格、筛选器、表单、卡片、分页、二级/三级侧边菜单、可折叠子菜单控件`
- Avoid: 不要生成 `游戏HUD`、`数据大屏`、`移动APP首页`、`PLC/HMI工控屏`、`设计工具画布界面`、`低质感XP老后台`

## 菜单层级规则

- 管理系统必须使用二级或三级菜单结构，不能只生成一级菜单。
- 推荐结构：左侧一级分组可折叠，展开后显示二级菜单；复杂页面继续显示缩进三级子菜单。
- 菜单视觉要体现层级：缩进、展开箭头、分组标题、选中态、父级高亮、子级悬停态。
- 主内容区可以是表格、表单、卡片或详情抽屉，但左侧导航必须能看出二/三级层级。
- 避免只有一列扁平菜单项、顶部单层导航或移动端 Tab 代替后台菜单。
